# React Pizza - Backend

Бэкенд часть пет-проекта интернет-магазина пиццы

## Возможности:
- Авторизация через GitHub OAuth
- Каталог пиццы с фильтрацией и сортировкой
- Работа с корзиной и оформление заказов (для авторизованных пользователей и гостей)
- Профиль пользователя (личные данные, история заказов)

## Стек:
- Node.js + Express
- TypeScript
- PostgreSQL + Prisma ORM
- JWT
- Zod
